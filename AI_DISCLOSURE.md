# AI Assistance Disclosure

## Project Title
**HealthLine PH**

## Purpose of This Disclosure

This document discloses the use of artificial intelligence (AI) tools as development assistance during the preparation of the HealthLine PH project and its documentation.

## Areas Where AI Assistance May Have Been Used

AI assistance may have been used for the following activities, as applicable to the actual development process:

- Explaining Flutter and Dart source code.
- Preparing project documentation and README content.
- Suggesting code improvements and debugging approaches.
- Explaining Firebase initialization, named routing, and Riverpod concepts.
- Assisting with the organization and description of application features.
- Providing suggestions for improving code readability and maintainability.

## Human Responsibility

AI-generated suggestions and documentation are treated as assistance rather than a substitute for the development team's work and judgment.

The project team is responsible for reviewing the code, validating functionality, checking the accuracy of documentation, testing application behavior, and ensuring that the implementation meets the project's requirements.

## Verification and Limitations

AI assistance does not guarantee that generated code is correct, secure, compatible with the existing codebase, or fully functional.

Features and technical claims should be verified against the actual source code, Firebase configuration, and application behavior. Any AI-generated code incorporated into the project should be reviewed and tested before submission or deployment.
